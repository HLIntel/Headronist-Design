# Background assets

The [asset inventory](../manifest.v1.json) lists project-original public backgrounds. These scalable network SVGs are decorative; pair them with semantic HTML and keep text outside the artwork.

Choose backgrounds for their purpose, measure text contrast over the actual surface, and check responsive crops, keyboard focus and reduced motion. See [asset sourcing](../../docs/ASSET-SOURCING.md) and the [visual lifecycle](../../docs/VISUAL-GENERATION-AND-GRAPHS.md).

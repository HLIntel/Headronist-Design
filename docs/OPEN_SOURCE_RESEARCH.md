# Research inspirations, not dependencies

- Vanilla Extract: build-time zero-runtime CSS (https://vanilla-extract.style)
- Radix/Base UI: behavior separated from appearance (https://www.radix-ui.com/primitives ; https://base-ui.com)
- Tailwind v4: CSS-first theme tokens (https://tailwindcss.com/docs/theme)
- Ghostty: fast defaults and lean configuration (https://ghostty.org)
- Vercel AI SDK: structured agent-friendly state (https://ai-sdk.dev)

Headronist implements original native patterns. No sign-up, payment card, hosted API or external asset fetch is required. Do not claim third-party assets are free forever; review licenses before redistributing anything.

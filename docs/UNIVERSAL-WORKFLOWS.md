# Universal Design Workflows

*Workflows · Tags: agents, interfaces, presentations, spreadsheets, docs · [Documentation index](README.md)*

Headronist is a task-directed design system, not a fixed aesthetic. The registry is the index; the intake is a bounded handoff; composition, quality, motion and platform guidance are loaded selectively.

| Medium | Priority | Typical output |
| --- | --- | --- |
| Website | editorial hierarchy, responsive behavior | HTML/CSS/JS |
| Application | state clarity, native patterns, accessibility | components and styles |
| Presentation | narrative rhythm, legibility, alignment | slide design guidance; renderer status must be checked |
| Spreadsheet | data clarity, number formatting, restrained emphasis | workbook design guidance; renderer status must be checked |
| Social graphic | crop safety, visual focal point, type contrast | image or vector brief |
| Documentation | scanability, examples, semantic headings | Markdown and diagrams |

Never claim a renderer exists merely because guidance exists. Prefer the smallest reusable fragment that solves the task. Avoid card walls, decorative badges, emoji and excessive effects. Keep source files portable, offline-capable and brand-neutral by default.

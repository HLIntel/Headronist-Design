# Headronist Design

A reusable, cross-medium design system for websites, landing pages, dashboards, Excel workbooks, PowerPoint decks, and vector graphics.

## Structure

- `foundations/`: palette library, semantic tokens, typography and accessibility
- `engines/`: backgrounds, imagery, surfaces, composition, motion
- `components/`: primitives, navigation, charts, data display
- `renderers/`: web, Excel, PowerPoint, documents, graphics
- `templates/`: landing, dashboard, pitch deck, financial report
- `contracts/`: versioned schemas
- `adapters/`: CSS, Tailwind and agents
- `tests/`: design verification

The complete migration, including preserved v10 HTML/CSS and executable v11 exporters, is prepared in the `Headronist-Design-v11.zip` artifact. The GitHub repository is **not yet fully synchronized** with that package.

Headronist owns visual presentation; Headron retains product logic, proof and governance.
